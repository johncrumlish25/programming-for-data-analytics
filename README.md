# Programming for Data Analysis

This repository contains my work for the Programming for Data Analysis module.

It includes weekly labs, assignments, datasets and the final project. The work is primarily completed using Python, Jupyter Notebook and various data analysis libraries.

## Repository Structure

The repository is organised into four main folders:

- **assignments** – Weekly assignments completed during the module.
- **data** – Data files used for exercises and analysis.
- **my-work** – Weekly labs and exercises completed during the module.
- **project** – Work relating to the Programming for Data Analysis project.

### Assignments Folder
The `assignments` folder contains the weekly assignments completed throughout the module.

| File | Description |
|---|---|
| `assignment02-bankholidays.py` | Working with Irish and UK bank holiday data. |
| `assignment03-pie.ipynb` | Creating pie charts of email domains. |
| `assignment04-population.ipynb` | Analysing population data and differences between sexes. |
| `assignment06-weather.ipynb` | Analysing and plotting weather data using pandas and seaborn. |

### Data Folder
The `data` folder contains datasets used throughout the weekly exercises and assignments, including CSV and JSON files.

### My-Work Folder
The `my-work` folder contains weekly labs, exercises and other practical work completed throughout the module.

| File | Description |
|---|---|
| `find-text.py` | Python exercise using regex. |
| `projectedbirths.ipynb` | Graphing birthrate data. |
| `read-csv.py` | Reading CSV files. |
| `read-json.py` | Reading JSON data. |
| `regression-windspeed.py` | Regression analysis involving windspeed. |
| `regression.py` | Regression analysis. |


### Project Folder
The `project` folder contains the work relating to the Programming for Data Analytics - Big Project.

- `project.ipynb` – Main project notebook.
- `project-data/` – Project datasets.
